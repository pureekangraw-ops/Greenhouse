AUTOMATION BOUNDARY

การทำงานอัตโนมัติและ Review

POLICY PREVIEW
01

งานปกติใน scope

ทำอัตโนมัติได้จนจบ พร้อม receipt/evidence/readback จากแหล่งจริง ไม่ต้องให้ GO/LIGHT อนุมัติทุกขั้น

02

Final action / งานเสี่ยงสูง

หยุดก่อน action สุดท้าย ให้ GO และ LIGHT ตรวจทั้งคู่ แล้วส่งให้ผู้มีอำนาจดำเนินการเอง

Review นี้เป็นแนวทาง UI เท่านั้น ยังไม่มี review queue หรือ command adapter เปิดใช้งาน

⌑

ขอบเขต: Greenhouse เป็น Owner Workspace และ readback surface ไม่ใช่ Work Ledger, Owner Source, Runner หรือ release authority. ใบรับงานแปลว่ารับ/ส่งข้อมูลแล้ว ไม่ได้พิสูจน์ว่าเครื่องมือทำงานสำเร็จ
